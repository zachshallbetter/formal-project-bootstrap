# Negative Results

Repository-level rejected directions are retained so later changes do not rediscover them as novel improvements.

## NR-001 — Generated context as optional convenience

**Rejected.** The operating method depends on cheap, coherent, reproducible agent access to the formal environment. Generated context is therefore required after initialization, while remaining strictly non-normative and rebuildable.

## NR-002 — Commercialization as the base project worldview

**Rejected.** Commercialization is a valid profile, not a universal project primitive. CALP/PGP remain optional overlays.

## NR-003 — Large permanent agent-role taxonomy

**Rejected.** Stable roles are kept minimal; domain specialization belongs in work packets, profiles, and skills. Permanent role proliferation increases context and coordination burden without demonstrated need.

## NR-004 — Exact root Git HEAD as context validity

**Rejected.** A tracked generated context file cannot truthfully contain the hash of the commit that contains itself. Context validity is bound to selected canonical-source contents. Git commit/branch/nested-repository state remains provenance and a reconciliation signal.

## NR-005 — Human instruction as invisible rule bypass

**Rejected.** Manual overrides are represented as scoped deviations so the governing state changes explicitly rather than forcing the worker to choose between standing doctrine and an ad hoc command.

## 2026-08-27 — Directed qualification is not behavioral-transfer evidence

**Rejected inference:** a worker that performs B5/B7/B8 after the evaluator prompt explicitly describes the expected response proves that the environment caused the behavior spontaneously.

**Why rejected:** the evaluator instruction is part of the causal input. Such a run is valid directed conformance evidence but cannot isolate behavioral transfer from prompt steering.

**Reopen condition:** none; this is a claim-boundary rule. Future work may establish behavioral transfer by withholding target-response restatement from the experiment prompt and comparing conditions prospectively.
